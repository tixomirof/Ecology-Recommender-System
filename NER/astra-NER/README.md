# Получение тестового датасета при помощи GPT-6-Astra Pro

Артефакты:
- `source_articles.csv` - исходные статьи и результат их парсинга с помощью компьютерного зрения
- `ner_comparison.ipynb` - получение метрик из разметок 2 экспертов и GPT-6-Astra Pro
- `ner_comparison_report.html` - визуализация метрик
- `annotation_evaluator.py` - мини-библиотека для оценки будущих разметок (получения метрик автоматически)
- `/data/*.jsonl` - разметки
